# CLI

Once `pyvista-wasm` has been installed, a
[console script](https://setuptools.pypa.io/en/latest/userguide/entry_point.html)
will be available with several convenience commands to assist with browser-based
3-D visualization.

```{eval-rst}
.. typer:: pyvista_wasm._cli.app
    :prog: pyvista-wasm
    :width: 75
    :preferred: html
    :theme: monokai
    :iframe-height: 800
```

## Commands

The following `pyvista-wasm` console script commands are available:

```{toctree}
plot
info
capture-preview
capture-marimo-preview
capture-stlite-preview
export-demo
check-locale-parity
```
